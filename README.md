# Alura Plus — Landing Page

Projeto de uma landing page desenvolvido durante os estudos de HTML e CSS, com o objetivo de praticar a estruturação e a estilização de páginas web a partir de uma proposta de divulgação de serviços digitais.

## 📌 Sobre o projeto

A página apresenta o **Combo+**, uma assinatura que reúne os serviços Alura+ e Alura Língua. O layout destaca os benefícios da plataforma, as opções de acesso em diferentes dispositivos e a possibilidade de baixar cursos para assistir offline.

O projeto busca reproduzir uma página de apresentação comercial, organizando informações, imagens e chamadas para ação em uma interface visualmente consistente.

## 🚀 Funcionalidades

- Apresentação do serviço Combo+.
- Exibição dos benefícios da assinatura.
- Seções informativas sobre dispositivos compatíveis.
- Apresentação da opção de download de cursos.
- Botões e links para ações relacionadas à assinatura.
- Layout adaptável a diferentes tamanhos de tela, conforme a implementação CSS.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo da página.
- **CSS3:** estilização dos elementos, definição do layout, cores, tipografia e espaçamentos.
- **Flexbox e Grid:** organização dos elementos na interface, conforme utilizados no projeto.
- **Media Queries:** adaptação do layout para diferentes tamanhos de tela, conforme implementado.
